## SOSA Actuation Feature

An Actuation is "the Act of carrying out an (Actuating) Procedure to change the state of the world via an Actuator." It is a specialisation of [Execution Properties](../execution/), adding `actsOnProperty` (the Property being changed) and `madeByActuator`.

This building block wraps [Actuation Properties](../../properties/actuation/) as a GeoJSON feature.
