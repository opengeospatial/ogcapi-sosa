## SOSA Actuator Feature

An Actuator is "a device that is used by, or implements, an (Actuating) Procedure that changes the state of the world." It is a specialisation of [System Properties](../system/), adding the `actsOn`/`isActedOnBy` relations to the Property it acts on.

This building block wraps [Actuator Properties](../../properties/actuator/) as a GeoJSON feature.
